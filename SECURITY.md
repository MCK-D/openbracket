# Security

This project is a synthetic educational demonstration. Do not enter real personal information. Report a suspected vulnerability privately with GitHub's **Report a vulnerability** feature, when enabled, or contact the repository owner through their GitHub profile. Do not open a public exploit report or include tokens.

Only the latest reviewed release is supported. Dependency updates are proposed weekly by Dependabot. The foundation uses an opt-in synthetic spectator sign-in, secure Auth.js cookies, server-side role checks, input validation, bounded public queries, and atomic audit writes. Full authentication, distributed rate limiting, comprehensive OWASP review, and backup validation remain tracked work. Never enable an administrator login through the demo provider.
