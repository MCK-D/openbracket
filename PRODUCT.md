# OpenBracket

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

T3: Next.js App Router, TypeScript, Prisma, PostgreSQL, tRPC, Auth.js, Tailwind CSS and shadcn/ui. Native Android is a separate client, never a WebView.

## Users and purpose

Administrators organize tournaments. Players enter and report results. Spectators predict results for points. Every signed-in player may also predict. This educational demonstration uses synthetic identities only and offers no money, purchases or valuable prizes.

## Constraints

English throughout. Original identity. WCAG 2.2 AA target. Public start.gg data only, with source attribution. Separate staging and production. This delivery is the core skeleton; the full product is tracked in GitHub Projects.

## Open decisions

The user selected Vercel Hobby and Neon Free, with independent staging and production projects. Plugin setup is reported complete; hosted resource access and activation still need verification. Product identity is provisional: OpenBracket follows the repository name. No final brand assets were supplied.
